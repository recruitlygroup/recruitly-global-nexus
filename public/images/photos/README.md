# Photography slots

All photos are referenced from `src/config/images.ts`. Drop licensed files here with the exact names below.
A missing file never breaks the page: a brand-navy gradient is shown instead, and the dark overlay keeps text legible.

## Standards
- **Full HD**: 1920 × 1080 (16:9) for full-bleed backgrounds; export as JPG or WebP, sRGB, ≤ 400 KB (quality ~75–80).
- **Overlays**: text sits on a semi-transparent ink overlay applied in code (`BackgroundPhoto`), so choose photos with
  calm areas on the left (hero) or lower third (cards). Avoid text, logos and watermarks inside the photo.
- **Rights**: licensed stock (Adobe Stock, Getty, Shutterstock) or your own photography with model releases.
- **Subject**: international recruitment and staffing — diverse professionals, handshakes/interviews, workers on site.
